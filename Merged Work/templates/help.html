Help & Guidelines

Quick guidance for using the Test Request Generator application.

What This Test Request Generator Does

The Test Request Generator is used to create, track, review, and complete EMC test requests in a structured workflow. It helps requesters submit complete test details, enables admins to assign TCO and govern approvals, allows lab engineers to plan and execute tests with datasheet uploads, and supports report review, download, and final admin sign-off.

1. Getting Started

  • Use Test Request to create and submit a new EMC test request.
  • Fill all required fields marked with a red asterisk (*).
  • Save as Draft if data is incomplete, then edit and resubmit later.

2. Request Queue

  • Users can see all of their submitted requests in their queue.
  • Use status, search, and comments indicators to quickly track request progress.
  • Use comments to communicate with reviewer/lab engineer throughout the workflow.

3. TCO, Planning, and Execution Workflow

  • Admin assigns the TCO and moves the request into the lab workflow.
  • Lab engineers plan tests under the assigned TCO and execute scheduled activities.
  • Lab engineers upload datasheets for completed test activities.

4. Report Review, Generation, and Sign-Off

  • After datasheets are uploaded, the report is uploaded for review.
  • Requester reviews the report and provides feedback/comments when needed.
  • After review, the report is finalized and can be downloaded from the application.
  • Admin performs final sign-off to complete and close the request.

Good Practice

Keep comments clear and actionable so requesters and reviewers can resolve issues in fewer cycles.
